# IPv6 Configuration Part 1 & 2

## Overview

These labs introduce IPv6 addressing and network configuration using Cisco IOS.

## Objectives

* Configure IPv6 addresses
* Configure network interfaces
* Enable IPv6 routing
* Verify IPv6 connectivity
* Troubleshoot addressing issues

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Configured IPv6 networks and verified end-to-end connectivity.
